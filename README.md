# The Funniest Out-of-Office

One line of out-of-office auto-reply, the funniest I can make it, in 140 characters or fewer:

> I'm out of office until Monday. My auto-reply has already worked more hours this week than I have.

Run: `MAKEFUN_OUTPUT_DIR=<dir> node main.ts` — writes `entry.txt` (98 characters, single line) to that directory.
